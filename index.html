Control Unit: Saare operations ko control karta hai. Instruction fetch, decode aur execute karwata hai

Q2. Conditional Transfer & Bus

Conditional Transfer: Condition true hone par jump hota hai. Ex: JNZ, JC

Bus Width: Data bus ki size. 8-bit, 16-bit, 32-bit

MUX: Multiple inputs me se 1 select karta hai using selection lines

Q3. Arithmetic & Logic

Addition: 1010 + 0110 = 10000

2's Complement: Number ko negative banane ke liye bits flip + 1 add

AND: 1.1=1 | OR: 1+0=1 | XOR: 1^1=0

Q4. 3-Bit Full Adder

Sum = A ⊕ B ⊕ Cin

Carry = AB + BCin + ACin

3 Full adders ko series me jor kar 3-bit adder banate hain. Pehle ka Cin = 0

Q5. Shift Operations

1. Logical Left: 1011 << 1 = 0110, right me 0

2. Logical Right: 1011 >> 1 = 0101, left me 0

3. Arithmetic Left: Same as logical left

4. Arithmetic Right: 1011 >> 1 = 1101, sign bit copy hota hai

Bonus: RISC vs CISC

RISC-V: Simple instructions, Fixed size, Load/Store, Compiler friendly, Less hardware

x86 CISC: Complex instructions, Variable size, Memory-Memory ops, Hardware friendly, Zyada power

Conclusion: RISC speed ke liye, CISC code size kam karne ke liye
